Cómo leer este dashboard

La curva muestra tasas spot por plazo; los pilares son nodos resueltos mediante bootstrap y los puntos interpolados son valores publicados por Nash para descontar flujos intermedios. El repricing evalúa consistencia y Atenea describe la forma de la curva.

Cómo funciona YieldCurve AI

Solicitud → Datos → Curva → Auditoría → Aprobación → Publicación

Elara valida, Siena obtiene datos, Nash construye, Atenea audita, Orion coordina y Nova permite consultar el sistema.

YieldCurve AI es una herramienta académica para análisis de renta fija. No ejecuta operaciones ni emite recomendaciones de inversión.
