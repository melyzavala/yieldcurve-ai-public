# Evidencia sanitizada P11

Estos JSON contienen únicamente estados observables, identificadores de caso sintéticos, rutas relativas, versiones y hashes de skills. No contienen secretos, credenciales, IDs de Telegram o n8n, encabezados, prompts privados ni razonamiento interno. Ejecute los comandos declarados en cada archivo desde la raíz del repositorio para reproducir la evidencia.

Los costos reflejan el comportamiento determinista local: cero llamadas LLM y cero consumo variable de API; infraestructura no medida se declara `null`, sin doble contabilización.
